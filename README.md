## 🌟 Overview

**Code Nova (Algoverse)** transforms traditional, abstract Computer Science concepts into tangible, interactive 2D and 3D visual experiences. Built for university students, self-taught developers, and competitive programmers, it unites theoretical concepts with interactive laboratories, real-time code execution, AI-assisted Big-O complexity detection, and multiplayer gamification.

### Why Code Nova?
- **Intuition-First Learning**: Instead of static code snippets, students manipulate live array pointers, step through Dijkstra's graph relaxations, rotate self-balancing AVL trees, and watch AES-256 byte matrix substitutions unfold in real-time.
- **Polyglot Flexibility**: Practice in Python, JavaScript, C++, or Java directly in the browser with an integrated Monaco editor and remote sandboxed execution.
- **Production-Grade Resilience**: Built with a dual-storage paradigm that gracefully balances cloud MongoDB Atlas connectivity with local zero-latency storage fallbacks.

## 🚀 Key Features

### 1. Data Structures & Algorithms Suite (40+ Algorithms)
Interactive step-by-step visualization, custom array/graph input generation, variable playback speeds, and live pointer tracking across 8 full categories:
- **Array Suite**: Static 1D Arrays, Dynamic Vectors (geometric doubling), 2D Matrices, Binary Search, Quick Sort (pivot partitioning), Merge Sort, Two Pointers (Two-Sum), and Kadane's Maximum Subarray.
- **Graph Suite**: Breadth-First Search (BFS), Depth-First Search (DFS), Dijkstra’s Shortest Path, A\* Pathfinding with Manhattan heuristics, Prim’s MST, Kruskal’s MST (Disjoint-Set Union), Bellman-Ford (negative cycle detection), and Topological Sort.
- **Tree Suite**: Binary Search Tree (BST) operations, AVL Tree self-balancing rotations (LL, RR, LR, RL), and traversals (In-order, Pre-order, Post-order, Level-order BFS).
- **Linked Lists**: Singly, Doubly, and Circular Linked Lists, Floyd’s Cycle Detection (Tortoise and Hare), and In-place Pointer Reversal.
- **Stacks & Queues**: LIFO Array Stacks, Syntax Bracket Parsing, Monotonic Stacks, Min-Stacks, Linear FIFO Queues, Circular Ring Buffers, Double-Ended Queues (Deque), and Priority Queues.
- **Heaps**: Binary Min-Heaps, Max-Heaps, Bottom-up Heapify ($O(N)$), and In-place Heap Sort.
- **Strings & Automata**: Knuth-Morris-Pratt (KMP with $\pi$ table), Rabin-Karp Rolling Hash, Z-Algorithm, and Expand-Around-Center Longest Palindromic Substring.

---

### 2. OOP Pillars Discovery Universe
Interactive visual simulators dedicated to the four cornerstones of Object-Oriented Software Design:
- **Encapsulation**: Visual data-hiding vault with state shields, access modifiers (`private`, `protected`, `public`), and getter/setter invariants.
- **Abstraction**: High-level interface Cockpit vs. internal circuitry, decoupling consumers from 10,000+ internal implementation nodes.
- **Inheritance**: Dynamic class trees spanning **Single Inheritance**, **Multilevel Inheritance**, and **Hierarchical Trees** with live method delegation and `super()` call traversal.
- **Polymorphism**: Dynamic runtime method dispatch, virtual method tables (vtables), and interface contracts executed across polymorphic derived classes.

---

### 3. Cryptography & Ciphers Suite (13 Engines)
A mathematical visual laboratory breaking down encryption, hashing, key exchange, and wartime cipher machinery:
- **Modern Standards**: **AES-256 (Rijndael)** featuring round-by-round 4x4 state matrix visuals (SubBytes, ShiftRows, MixColumns, AddRoundKey) and **RSA Public-Key Cryptosystem** with prime factoring and Euler totient trapdoor generation.
- **Key Exchange & Authentication**: **Diffie-Hellman (DH)** color-mixing / discrete logarithm agreement and **Digital Signatures** (SHA-256 hashing + asymmetric verification).
- **Hashing & Privacy**: **SHA-256** 512-bit chunk scheduling and bitwise operations, alongside **LSB Image & Text Steganography**.
- **Classical & Transposition**: **Caesar Cipher**, **Vigenère Tableau**, **Playfair 5x5 Matrix**, **Rail Fence**, and **Columnar Transposition**.
- **Historical Machinery**: Fully simulated mechanical **Enigma Machine** with reconfigurable rotors, reflector, and plugboard (*Steckerbrett*).

---

### 4. Polyglot Code Sandbox with Gemini AI
- **Multi-Language Support**: Write, compile, and execute code in **Python 3**, **JavaScript (Node.js)**, **C++17**, and **Java 17**.
- **Sandboxed Cloud Execution**: Integrated with isolated JDoodle container engines with execution timeouts and output limits.
- **Automated Big-O Complexity Detection**: Powered by **Google Gemini 2.0 Flash** (with OpenRouter fallback) analyzing code to deduce exact Time Complexity, Space Complexity, utilized Data Structures, and runtime explanations.
- **Deterministic AST Static Analyzer**: If network or AI limits are reached, a built-in static AST analyzer immediately steps in to determine loop nesting, recursion depth, and divide-and-conquer logarithmic steps.

---

### 5. 3D Game World & Real-Time 1v1 Duels
- **Interactive 3D Terrain**: Explore an open 3D algorithm world built with Three.js, React Three Fiber, and Rapier physics.
- **Real-Time 1v1 PvP Duels**: Socket.IO matchmaking pairs competitors in live algorithm battles with synchronized timers, dynamic question delivery, real-time health bars, and instant score resolution.
- **Tournaments & Competitions**: Host and enroll in scheduled timed competitions with live global XP and accuracy leaderboards.
- **AI Coding Hint System**: Stuck on a challenge? Spend earned XP to request a smart, non-spoiling hint synthesized by Gemini AI.

---

### 6. Virtual 3D Interactive Library
- A rendered, spatial Three.js room with checkered marble tiles, brass floor lamps, reading tables, and interactive bookshelves.
- Users can rotate the camera, inspect individual 3D bookshelves, and click categorized book spines to jump directly into Data Structures, OOP Pillars, Cryptography, or Sandbox environments.

## 🔬 Engineering Highlights & Technical Accomplishments

1. **GPU-Accelerated 3D Performance**:
   - Particle field with 18,000+ points driven by custom GLSL shaders, critically damped dampening controllers (`MathUtils.damp`), and Bloom post-processing that maintains stable 60 FPS rendering.
2. **Multi-Tier Fault Tolerance & Fallback Pipelines**:
   - **Database**: The backend automatically detects MongoDB Atlas network connectivity. If unreachable or timeout occurs, it seamlessly transitions into an internal persistent storage engine without crashing or disrupting student logins.
   - **AI Complexity Inference**: Three-stage resilience pipeline: *OpenRouter Free Models* $\rightarrow$ *Native Google Gemini API* $\rightarrow$ *Deterministic Static AST Parser*.
3. **Defense-in-Depth & Container Security**:
   - Strict request body size capping (max 50KB code payload) to thwart DoS memory flooding.
   - Execution isolation via JDoodle with a hard 15-second execution timeout.
   - Comprehensive error sanitization ensuring internal file paths, tokens, and stack traces are never exposed to clients.
4. **Clean Code & Modular State Management**:
   - Frontend leverages **Zustand** for lightweight reactive application-level store (themes, active visualizer state) and **React Router v7** for deep-linkable algorithm states.

## 📡 REST API & WebSocket Documentation

### Authentication (`/api/auth`)
| Method | Endpoint | Access | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Public | Create new account, hash password with bcrypt, issue verification token |
| `POST` | `/api/auth/login` | Public | Verify credentials, check rate limits, and return JWT token |
| `GET` | `/api/auth/verify-email` | Public | Verify user account with URL token |
| `POST` | `/api/auth/resend-verification` | Public | Resend email verification code |
| `GET` | `/api/auth/me` | Protected | Return currently logged-in user profile & XP stats |
| `POST` | `/api/auth/logout` | Protected | Invalidate session |

### Code Execution & AI Sandbox (`/api/sandbox` & `/api/ai`)
| Method | Endpoint | Access | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/sandbox/execute` | Protected | Execute code in Python, JS, C++, or Java via JDoodle (15s timeout) |
| `POST` | `/api/sandbox/visualize` | Protected | Analyze code with Gemini / AST analyzer for Big-O time and space |
| `POST` | `/api/ai/hint` | Protected | Deduct 50 XP and generate smart algorithm hint using Gemini |

### Competitions & Contests (`/api/competitions`)
| Method | Endpoint | Access | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/competitions/create` | Protected | Host a new competitive contest |
| `POST` | `/api/competitions/generate-tests` | Protected | Dynamically generate coding challenges and test cases |
| `POST` | `/api/competitions/:id/enroll` | Protected | Register user for competition |
| `POST` | `/api/competitions/:id/submit-score`| Protected | Record submission time, accuracy, and score |
| `GET` | `/api/competitions/:id/leaderboard` | Public | Fetch real-time competition standings |

### Real-Time WebSockets (`socket/duelManager.js`)
| Event Name | Direction | Payload / Purpose |
| :--- | :--- | :--- |
| `joinQueue` | Client $\rightarrow$ Server | Enqueue player for 1v1 matchmaking |
| `matchFound` | Server $\rightarrow$ Client | Both players paired; emit room ID and opponent profile |
| `submitAnswer` | Client $\rightarrow$ Server | Submit answer index; calculate score and accuracy |
| `duelUpdate` | Server $\rightarrow$ Client | Sync health bars, scores, and round progression |
| `duelEnded` | Server $\rightarrow$ Client | Conclude duel, award winner XP, and record duel history |

## 💻 Getting Started & Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [Git](https://git-scm.com/)
- *Optional*: A free [MongoDB Atlas](https://www.mongodb.com/) cluster, [JDoodle API credentials](https://www.jdoodle.com/compiler-api/), and a [Google Gemini API Key](https://ai.google.dev/).

---

### 1. Backend Setup

1. **Navigate to the backend directory**:
   ```bash
   cd backend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file inside the `backend/` directory:
   ```env
   PORT=5000
   FRONTEND_URL=http://localhost:5173
   JWT_SECRET=your_super_secret_jwt_key_here

   # Database (Leave blank to automatically use local resilient storage engine)
   MONGODB_URI=your_mongodb_connection_string

   # Remote Code Execution (JDoodle API)
   JDOODLE_CLIENT_ID=your_jdoodle_client_id
   JDOODLE_CLIENT_SECRET=your_jdoodle_client_secret

   # AI Complexity Analyzer & Coding Hint System
   GEMINI_API_KEY=your_google_gemini_api_key
   OPENROUTER_API_KEY=your_openrouter_api_key
   ```

4. **Start the backend server**:
   ```bash
   npm start
   # Server will run on http://localhost:5000
   ```

---

### 2. Frontend Setup

1. **Open a new terminal and navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the Vite development server**:
   ```bash
   npm run dev
   # Frontend will run on http://localhost:5173
   ```

4. **Open your browser** and visit `http://localhost:5173`. You can register a new account or immediately explore public visualizations!
